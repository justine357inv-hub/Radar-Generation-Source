Counter-Strike: Source mapping tool

Generate accurate radar textures from VMF geometry.

Radar Generation: Source parses Valve Map Format files and produces multi-level radar textures and Source-compatible radar materials.

Download the app Read the documentation

What it does

Built for Source mapping workflows

VMF parsing

Reads Valve Map Format geometry and uses it as the basis for radar generation.

Multi-level support

Generates radar output for maps with multiple floors and vertical gameplay areas.

Source-ready output

Produces radar textures and materials that can be used in Counter-Strike: Source.

Workflow

From map geometry to playable radar

  1. Prepare or export your map's VMF file.
  2. Run Radar Generation: Source.
  3. Configure the generation options.
  4. Copy the generated radar files into your game installation.
